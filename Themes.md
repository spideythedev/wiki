### corbon

A lightweight, customizable Zsh prompt theme with configurable layouts, Git status, runtime information, and optional environment indicators.

**Features:**
- Configurable prompt layouts and color palettes
- Git branch and working-tree status
- Runtime version indicators
- Command execution duration and exit status
- Optional system and development environment information

**Installation:** See the repository README for installation and configuration instructions.
